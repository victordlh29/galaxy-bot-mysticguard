Actividad de Discord (canal de actividad)
URL de la actividad
Pasos para activarla
1. Developer Portal → tu app → Activities.
2. Activa Application URL Override y pega: http://localhost:3000/activity
3. (El apartado "URL Mappings" NO se usa para esto: es para proxear APIs externas).
4. En Discord: Configuración → Avanzado → Modo desarrollador ON.
5. Entra a un canal de voz → botón 🚀 Actividades → lanza GALAXY BOT.
Comando /activity
Los usuarios pueden usar /activity en el servidor para que el bot muestre el enlace de la actividad.
Servidores donde está el bot
Todos los servidores en los que el bot está presente. El que tiene el sello GESTIONADO es el servidor por defecto (guardado en la base de datos). Haz clic en cualquier tarjeta para entrar a ese servidor.
